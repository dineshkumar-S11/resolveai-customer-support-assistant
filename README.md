# 🤖 ResolveAI – AI Powered Customer Support Assistant

ResolveAI is an AI-powered customer support dashboard designed to help organizations manage customer tickets efficiently. The system provides ticket tracking, analytics, AI-assisted resolutions, and customer support insights through a modern dashboard interface.

## 🚀 Features

- 🎫 Ticket Management System
- 🤖 AI Assisted Ticket Resolution
- 📊 Dashboard Analytics
- 📈 Ticket Statistics & Charts
- 🥧 Resolved vs Escalated Analysis
- 🌙 Dark Mode Support
- 🔔 Notifications Panel
- ⏰ Live Date & Time
- 🔍 Search Functionality
- 📱 Responsive Design
- 📚 Knowledge Base Categories
- 👥 Customer Management Dashboard

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- FastAPI
- Chart.js
